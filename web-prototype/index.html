How to use (30s)
  1. A clicks Create session, selects a file, copies offer to B.
  2. B pastes offer, clicks Join, copies answer back to A.
  3. A pastes answer, clicks Connect, then Send file.
  4. B watches progress; on complete the download link appears (checksum verified).
